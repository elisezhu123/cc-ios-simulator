# iOS Simulator 插件 · 面板截图标注设计

- 日期：2026-09-30
- 状态：已实现
- 参考：Claude Code 桌面版 iOS 模拟器的标注工具条（交互参考，没有移植代码）

## 1. 目标

用户在面板里直接在截图上标出问题（"这个按钮""这里的间距不对"），然后交给 Claude。

## 2. 已确定的决策

| 决策 | 结论 |
|---|---|
| 入口 | 工具栏的铅笔按钮：先截一张原尺寸截图（`/api/capture`，模拟器和真机都行）冻结在画面上，再显示底部的标注工具条 |
| 工具 | 画笔、直线、箭头、矩形、椭圆、文字；红、蓝、绿、黑、白 5 种颜色；撤销 / 重做 / 清空（清空也能撤销）；快捷键 ⌘Z、⇧⌘Z、⌘↩、Esc |
| 坐标 | 图形存成**截图像素**坐标：屏幕上按显示比例绘制，导出时按 1:1 绘制，所以导出图和截图一样清晰。线宽和字号按截图长边的比例取，任何分辨率下看起来都一样 |
| 文字 | 带反差描边（白字配深色描边，其他颜色配白色描边），放在任何背景上都看得清 |
| "添加到对话" | 面板是独立网页，没法直接往 Claude 的对话框里塞内容。所以：① 把合成后的 PNG 发给服务端，存到 `<缓存>/annotations`（最多保留 30 张，每张配一个记录设备和"已查看"状态的 JSON）；② 同时尽量复制到剪贴板，方便直接粘贴 |
| 交给 Claude | 新工具 `ios_sim_annotation`（第 31 个）：默认返回最新一张（图片 + 设备、尺寸），`index` 取更早的，`list: true` 只列清单；返回后标为已查看。有未查看的标注时，`ios_sim_screenshot` 的结果会带 `userAnnotations` 提示 |
| 安全 | 沿用面板的安全检查（只允许本机、校验 Origin、要求 JSON 请求体）；只接受 `data:image/png;base64`，并检查 PNG 文件头；请求体上限按 24 MB 的 PNG 计算；`/annotations/<名称>` 只提供符合命名规则的文件，拒绝符号链接和路径穿越 |

## 3. 验证

- 新增测试 6 个：撤销 / 重做历史、尺寸与箭头几何、绘制（用记录器代替真实画布）、存储（编号、已查看状态、清理旧文件、缺少 JSON 记录时的处理）、`POST /api/annotations`（保存与各种拒绝情况）、`ios_sim_annotation` 工具与截图提示。
- 用无头 Chromium 驱动构建后的面板：六种工具、换色、撤销、中文文字输入都正常；"添加到对话"后得到 1206×2622 的标注图，提示已复制，控制台没有错误。
