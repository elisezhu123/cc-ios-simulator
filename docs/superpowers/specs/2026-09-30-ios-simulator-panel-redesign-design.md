# iOS Simulator 插件 · 面板界面改版设计

- 日期：2026-09-30
- 状态：已实现
- 参考：Claude Code 桌面版自带的 iOS 模拟器面板（仅参照布局和交互，没有移植代码，也不使用其品牌标识）

## 1. 布局

| 区域 | 内容 |
|---|---|
| 标题栏 | "iOS Simulator"、连接状态、全屏 |
| 菜单栏 | 设备选择（分组：已启动 / iPhone·iPad / 未启动，当前设备打勾）· 设备菜单 · 调试菜单 |
| 画面 | 默认"真机框"：黑色边框、金属外圈和侧边按键（横屏时隐藏按键），背景是浅色渐变 |
| 底部工具条 | 回到桌面 · 标注、保存截图、录制视频 · 向右旋转 · 关闭模拟器、断开模拟器；悬停显示名称和快捷键，后两个悬停时显示红底 |

## 2. 已确定的决策

| 决策 | 结论 |
|---|---|
| 菜单实现 | 自己写的弹出菜单（`client/menu.ts`）：分组标题、分隔线、勾选、快捷键提示、悬停展开子菜单（右侧放不下时向左展开）；每次打开都重新生成菜单项，内容总是反映当前状态。在菜单栏上滑过时会切换到相邻菜单 |
| 设备菜单 | 外观（浅色 / 深色，走 `simctl ui appearance`）、键盘 ▸ 显示屏幕键盘、左右旋转、回到桌面、后台 App、摇一摇、Action 按钮、窗口重新居中、锁屏 / 解锁 / Siri。真机只保留旋转和锁屏 / 解锁 / Siri |
| 调试菜单 | 慢动画、显示大小、外框、重新连接画面 |
| 新的设备操作 | `toggle-keyboard`（I/O ▸ Keyboard ▸ Toggle Software Keyboard）和 `slow-animations`（Debug ▸ Slow Animations），通过点击 Simulator.app 的菜单实现；菜单脚本支持多级路径。`ios_sim_interact device_action` 也能用 |
| 快捷键 | ⇧⌘H 回到桌面、⌘S 保存截图、⌘R 录屏、⌘→ / ⌘← 旋转、⌘K 屏幕键盘（非 Mac 上用 Ctrl）。不占用浏览器无法拦截的组合（如 ⌘T）；标注或输入文字时不触发 |
| 保存截图 | 截原尺寸 PNG，以"Simulator Screenshot - 设备 - 时间.png"的文件名下载 |
| 录屏 | 新接口 `POST /api/record {action}`，使用插件已有的 Recorder；状态接口返回 `recording`，按钮变成停止图标 |
| 关闭模拟器 | `POST /api/shutdown`：和 `ios_sim_shutdown` 的顺序一样，先停止录屏和画面，再关机 |
| 断开 | `POST /api/detach`：模拟器只停止画面、保持运行；真机时回到模拟器 |
| 真机 | 录屏和关闭模拟器按钮置灰（提示"仅模拟器可用"），模拟器专用接口返回 400 |

## 3. 验证

- 新增测试 3 个：录屏开始 / 停止与状态、外观切换、真机上的拒绝；关闭模拟器先停录屏和画面，断开不关机、真机时断开会回到模拟器；多级菜单脚本。
- 用无头 Chromium 驱动构建后的面板：设备分组和打勾、设备菜单和键盘子菜单、调试菜单、工具条提示都正常；⌘S 下载、⌘R 开始 / 停止录屏、外观切换、横屏布局都正常；标注在新布局下照常工作，控制台没有错误。
