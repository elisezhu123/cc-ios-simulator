🚀 快速开始
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方法1 - 自动配置 (推荐):

  npm run configure

方法2 - 安装脚本:

  ./install.sh

方法3 - 手动配置:

  1. npm install && npm run build
  2. 编辑配置文件:
     ~/Library/Application Support/Claude/claude_desktop_config.json
  3. 添加服务器配置 (见 claude_desktop_config.example.json)
  4. 重启 Claude Desktop

🎯 使用方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 配置完成后，重启 Claude Desktop

2. 打开模拟器:
   open -a Simulator

3. 在 Claude Desktop 中说:
   "打开 iOS 模拟器面板"
   或
   "Open the iOS simulator panel"

4. 右侧会出现实时预览面板！

🔧 MCP Tools
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. simulator_open_panel
   打开实时预览面板 (包含 UI resource)

2. simulator_list
   列出所有可用的模拟器

3. simulator_boot
   启动指定的模拟器

4. simulator_shutdown
   关闭运行中的模拟器

5. simulator_screenshot
   截取模拟器屏幕

6. simulator_home
   按 Home 键返回主屏幕

7. simulator_rotate
   旋转设备 (left/right)

🤔 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 面板显示 "No booted simulator"?
A: 先启动模拟器: open -a Simulator

Q: 工具没有出现在 Claude Desktop?
A: 检查配置文件路径，重启 Claude Desktop

Q: 截图不更新?
A: 点击 Refresh 按钮，或检查模拟器是否在前台

Q: 想要更快的刷新?
A: 编辑 src/ui/index.html，修改 setInterval 的毫秒数
